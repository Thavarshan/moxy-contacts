# Security Policy

## Supported versions

Security fixes are made for the latest code on the `main` branch. Older commits
and releases are not supported.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue or pull request.
Use GitHub's **Report a vulnerability** feature on the repository's Security tab
to send a private report. If that option is unavailable, contact the maintainer
through [GitHub](https://github.com/Thavarshan) and ask for a private reporting
channel. Include the affected version, impact, and steps to reproduce; do not
include real contact records or other people's personal information.

The maintainer will acknowledge reports and coordinate any fix and disclosure
with the reporter. There is no guaranteed response or release timeline.
