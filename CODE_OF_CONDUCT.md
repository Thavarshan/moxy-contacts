# Code of Conduct

Moxy Contacts is a community for people building and using a privacy-conscious
contacts archive. We expect everyone who participates in project spaces to help
keep them welcoming and respectful.

Examples of unacceptable behavior include harassment, discriminatory or sexualized
language, personal attacks, publishing someone's private information, and sustained
disruption of project discussions.

Project maintainers may remove or edit contributions that violate this code and
may block accounts from project spaces when needed to protect participants.

To report a conduct concern, contact the maintainer through [GitHub](https://github.com/Thavarshan).
For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening
a public issue.
